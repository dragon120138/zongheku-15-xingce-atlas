# 【综合库15】 行测图谱

> 考试 · 知识图谱（讲坛＋图谱）

## 关于

行测知识图谱：言语、数量、判断、资料与常识五大模块的题型方法网络。

讲坛页面按学习路径串联知识节点，图谱页面展示整体结构——两者是同一批知识的两种视图，都是本库的精华部分。

## 使用

1. 下载本仓库（Code → Download ZIP）并解压；
2. 打开 `index.html`（Chrome / Edge 直接打开，无需服务器）；
3. 图谱与讲坛页面均为本地静态资源。
